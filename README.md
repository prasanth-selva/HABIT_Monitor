# Streakly (scaffold)

This workspace contains the initial scaffold for the Streakly Flutter habit tracker app. It includes:

- `pubspec.yaml` with required dependencies
- `lib/main.dart` app entry with Hive initialization stub
- Core constants and theme files
- Hive model stubs for `HabitModel` and `CompletionModel`
- Simple local datasource wrapper around Hive
- Domain entities and basic Riverpod provider stubs

Next steps: generate Hive adapters and Riverpod code, implement repositories, and build UI screens.
